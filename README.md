## 📖 Tentang Projek

**Green Point of Sales** adalah aplikasi desktop yang dirancang khusus untuk mempermudah proses transaksi dan manajemen produk. Dibangun dengan fokus pada kecepatan pemrosesan logika dan keandalan data, sistem ini sangat cocok untuk menangani alur kasir sehari-hari secara *real-time* tanpa hambatan.

## ✨ Fitur Utama

- 📦 **Manajemen Produk:** Sistem pendataan barang terstruktur (tambah, edit, hapus, dan perbarui stok).
- 🛒 **Transaksi Cepat:** Pemrosesan transaksi kasir yang responsif.
- 🗄️ **Database Handal:** Integrasi relasional yang aman untuk penyimpanan data riwayat dan inventaris.
- 🖥️ **Antarmuka Intuitif:** Desain form yang bersih, fungsional, dan ramah pengguna.

## 🛠️ Tech Stack

Projek ini dikembangkan menggunakan teknologi:
- **Framework & UI:** C# (Windows Forms)
- **Logika Sistem & Backend:** C#
- **Database:** PostgreSQL
